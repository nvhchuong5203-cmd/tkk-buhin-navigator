# TKK 部品ナビ

Ứng dụng PWA tĩnh được triển khai tự động bằng GitHub Pages.

## Cập nhật

1. Thay các tệp cần cập nhật trong thư mục `dist`.
2. Commit và push lên nhánh `main`.
3. GitHub Actions tự động triển khai lại, giữ nguyên đường link Pages.

Có thể chạy thủ công tại **Actions → Deploy GitHub Pages → Run workflow**.
